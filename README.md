# 青溪县山区电子异常勘察 · 行动记录

一部中文多媒体互动小说。

这个仓库里只有一个 `index.html`：正文、图片、音频、动效全部内联在这一个文件里。双击即可阅读，不需要联网、不需要安装任何东西、也不需要本地服务器。

## 在线预览

`https://island067.github.io/qingxi-record/`

> 在仓库 Settings → Pages 里开启「Deploy from a branch / main / (root)」后，上面的地址即可访问。

## 30 秒打开

- **电脑（Windows / macOS）**：下载 `index.html`，双击，用浏览器打开。第一次要解析约 25 MB，1–3 秒属于正常。
- **安卓 / 鸿蒙手机**：把 `index.html` 发到微信 → 点开文件 → 「用其他应用打开」→ 选浏览器。
- **iPhone / iPad**：不能直接点开 html（iOS 的「文件」App 只做预览、不执行脚本）。请用上面的在线预览地址，在 Safari 里打开。
- **第一次可能没声音**：先点一下页面任意位置（浏览器的自动播放限制）；Safari 还不行就到「设置 → 网站 → 自动播放 → 允许」。
- 全流程约 10 分钟；正文看完记得一直拉到底。

## 素材与音频来源

- 图片由提示词生成，提示词原件保存在项目内（`prompt-kit`），未随本仓库发布。
- 音频**全部内联在 `index.html` 内部；本仓库不包含任何独立的音频文件**（没有 mp3 / wav 文件，也没有 `assets` 目录）。
- 其中第三方素材包括：`236.wav`（进场）、三条界面环境音、烟雾警报、Windows XP 提示音、buddhist 采样，以及结尾蓝屏上的 *the neverminds - dusk_L*。
